An experimental **overhaul mod** for Tales of Eternia Remastered on **Windows / Steam**.

## Download and install

**[Download 0.13.8 — Easy Install](https://github.com/Water130/tales-of-eternia-waters-edition/releases/download/v0.13.8-test/Tales-of-Eternia-Waters-Edition-0.13.8-Easy-Install.zip)** · [All releases](https://github.com/Water130/tales-of-eternia-waters-edition/releases)

Requires **Steam build 25190541**. Back up your saves and close the game first.

1. Extract the entire ZIP.
2. Run **Install.cmd**, check the game folder, then confirm with **Y**.
3. Wait for **Installed and verified**, then launch the game through Steam.

**To uninstall:** close the game, run **Uninstall.cmd**, and confirm with **Y**.
Uninstall an older release with its own uninstaller before updating.
No Python or mod loader is needed. [Installation help →](docs/INSTALLATION.md)

## What it changes

- **Combat:** TP recovery, dynamic camera, supported overlapping spells and optional control changes.
- **Artesphere:** three pages of six assignments, with configurable keyboard controls.
- **Progression:** spell usage mastery, Farah's Energy healing faculties and mastery menus.
- **Interface:** custom HUD, casting/cooldown bars, elemental colors and skit notifications.
- **Settings:** grouped options with saved choices. Mod text is French or English.
