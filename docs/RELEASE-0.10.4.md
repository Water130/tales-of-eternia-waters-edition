## Download and install

Download **Tales-of-Eternia-Waters-Edition-0.10.4-Easy-Install.zip** from the assets below. Close the game, extract the ZIP,
double-click **Install.cmd**, then type **Y** and press Enter.
The installer finds your Steam folder automatically and preserves the original file.

To remove the mod, close the game, double-click **Uninstall.cmd** and confirm with **Y**.
No Python or mod loader is required. The installer and uninstaller do not directly edit saves.

## Included

TP recovery changes, a smoother dynamic camera, limited spell overlap, elemental
casting/damage colors, custom HP/TP HUD, casting/item bars, Craymel vitality icons,
held-cast/full-vitality summon controls, skipped startup presentation screens,
blue title branding and the native-style Mod settings page.

Seven settings can be toggled independently. Mod text is French for French game text,
and English for other languages. All installation prompts and documentation are in English.

## Limits

This is a test release. Some camera/summon edges still need testing; same-effect and
special spells remain queued. Compatibility mode restores the native spell queue.

If upgrading from an earlier version, uninstall that version first. Unsupported game
updates and other modified DLLs are rejected automatically.
