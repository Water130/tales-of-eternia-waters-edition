INSTALL
1. Close the game. Right-click this ZIP and choose "Extract All".
2. Open the extracted folder and double-click Install.cmd.
3. Check the detected game folder, type Y and press Enter.
4. Wait for "Installed and verified", then start the game through Steam.

UNINSTALL
1. Close the game and double-click Uninstall.cmd in this same folder.
2. Check the detected game folder, type Y and press Enter.
3. Wait for "Original game restored and verified".

The installer finds your Steam libraries automatically. If it asks for a path:
in Steam, right-click the game > Manage > Browse local files, then copy that
folder's path and paste it into the installer. Press Enter to continue.

Keep Install.cmd, Uninstall.cmd and the Support folder together.
No Python, mod loader or extra download is required.
The installer does not directly edit saves. The original game file is backed up for removal.
Uninstalling keeps your mod preferences and the original backup.

IF UNINSTALLING FAILS
Close the game and try Steam's game-file verification:
Steam Library > game Properties > Installed Files > Verify integrity of game files.
Official guide: https://help.steampowered.com/en/faqs/view/0C48-FCBD-DA71-93EB
Reinstalling the game may be necessary if problems persist. Verification and
reinstallation do not guarantee recovery of damaged saves or lost progress.

In the game, open "Mod settings" on the title screen to switch features on/off.
Mod text is French with French game text, and English with every other language.

If an older mod version is installed, uninstall it using its own Uninstall.cmd
first. This installer refuses unsupported game versions and other modified DLLs.
