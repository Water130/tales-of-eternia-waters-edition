# Water's Edition 0.14.11 — Easy Install

Experimental release for **Tales of Eternia Remastered, Windows / Steam build 25190541**.
This is the **same archive as [the official Nexus Mods release](https://www.nexusmods.com/talesofeterniaremastered/mods/13)**.

## What is included

- **72 active Craymel faculties**, earned spirit EXP and summon growth.
- Five offensive spell growth tracks, separate mage progression and x3 catch-up uses.
- French/English notifications for both spell levels and individual bonus levels.
- Farah Energy healing, mixed-branch extra normal attacks, four standalone team-up
  artes and optional Reid special-technique changes.
- Scan memory and compact R1 info, revised mastery menus, EXP bars and saved option groups.
- Three Artesphere pages and the existing combat, camera and quality-of-life options.

Most features can be toggled: use the parts you want. Related progression systems
share coherent switches. **Fringe: free cages remains off by default.**

## Install or update

Download **Tales-of-Eternia-Waters-Edition-0.14.11-Easy-Install.zip** below, not the Source code archives.
Back up your saves and `%LOCALAPPDATA%\TalesOfEternia-WatersEdition.ini`.
Close the game; if updating, uninstall the older release with its own **Uninstall.cmd**.
Extract the entire new ZIP, run **Install.cmd**, check the game folder and confirm
with **Y**. Wait for **Installed and verified**. No Python or mod loader is needed.

The installer checks the supported original DLL and ships only binary differences.
Other mods changing GameNative.dll are not automatically compatible.
