# Water's Edition 0.13.8 — Easy Install

Experimental overhaul for **Tales of Eternia Remastered — Windows / Steam build 25190541**.

## What's new

- Mastery menus with rooted trees and two five-column spell pages.
- Farah's Energy healing faculties and optional offensive spell usage mastery.
- Grouped mod settings, separate Reid/Farah jump controls, arte labels and quick skit playback.

Physical arte-chain and Craymel faculty trees are previews in this version.
[Full changes](https://github.com/Water130/tales-of-eternia-waters-edition/blob/main/CHANGELOG.md)

## Install

Download **Tales-of-Eternia-Waters-Edition-0.13.8-Easy-Install.zip** from Assets below.
Back up saves and mod preferences; close the game. Extract the ZIP, run **Install.cmd**,
check the folder and confirm with **Y**. No Python or mod loader is needed.

For updates, uninstall the old version with its own uninstaller first.
To remove this release, close the game and run **Uninstall.cmd**.
