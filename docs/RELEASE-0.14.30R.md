## Install or update

Windows / Steam build 25190541. Uninstall your previous version with its own
uninstaller first. Close the game, extract the entire Easy-Install ZIP,
run Install.cmd and confirm the game folder with Y. No Python or mod loader is
required. Unknown or modified game files are refused. Keep original backups.
Back up saves and `%LOCALAPPDATA%\TalesOfEternia-WatersEdition.ini` separately.
