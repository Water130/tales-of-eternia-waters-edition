# Water's Edition 0.14.30

- Added **Spark Wave** (*Vague d'étincelles*), learned through **Volt level 5**.
- Added **Fear Flare** (*Rafale ardente*), learned through **Efreet level 10**.
- Both spells are available to Keele and Meredy through the appropriate Craymel cage.
- Spell mastery now reaches its maximum at **500 uses**.
- Updated mastery pages, controls and combat displays.
- Restored the original HP/TP digit style in French battles.
- Updated installation checks and original-file backups.

## Installation

Requires **Windows / Steam build 25190541**. Back up your saves and mod settings, close the game and uninstall the previous version with its own uninstaller before updating. Extract the whole mod archive and run **Install.cmd**.
