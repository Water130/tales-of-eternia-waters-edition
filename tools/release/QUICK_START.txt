WATER'S EDITION - INSTALLATION

Requires Windows / Steam build 25190541. Keep at least 5 GiB free.

1. Back up your saves and mod settings, then close the game.
2. Extract the entire archive. Keep Install.cmd, Uninstall.cmd and Support together.
3. Run Install.cmd, check the game folder and confirm with Y.
4. Wait for "Installed and verified", then launch the game through Steam.

Update: uninstall the previous version using its own uninstaller first.
Remove: close the game and run Uninstall.cmd. Keep the original-file backups.
If removal fails, Steam's file verification can restore the game files, but
may also replace changes made by other mods.

Back up %LOCALAPPDATA%\TalesOfEternia-WatersEdition.ini alongside your saves.
This file stores mod settings, extra assignments and progression data;
Steam Cloud does not automatically include it.

Full instructions: https://github.com/Water130/tales-of-eternia-waters-edition/blob/main/docs/INSTALLATION.md
